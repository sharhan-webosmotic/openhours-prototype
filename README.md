# Open Hours

Open Hours is a React and Vite clinic operations dashboard for cardiology appointments, patient records, doctor availability, services, and call history.

## Run locally

```sh
npm ci
npm run dev
```

Create a production build with `npm run build`. Vite writes the site to `dist/`.

## Deploy with Vercel

Import this repository into Vercel. The included `vercel.json` configures the Vite build, `dist` output, and single page app fallback.
